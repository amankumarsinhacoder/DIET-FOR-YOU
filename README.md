# Nourish Day — HTML, CSS and JavaScript

## Run locally

1. Extract the ZIP file.
2. Open `index.html` in any modern browser.

No framework, package installation, build command, server or API key is required.

## Files

- `index.html` — nutrition calculator and meal-plan interface
- `workout.html` — personalized workout-plan page
- `styles.css` — complete responsive styling
- `script.js` — calorie, macro and meal-plan calculations
- `workout.js` — goal-based workout generation
- `assets/meal-bowl.png` — meal image

The formulas use the Mifflin–St Jeor equation to estimate basal metabolic rate, an activity multiplier for maintenance calories and goal-specific adjustments for weight loss, body recomposition or weight gain.
